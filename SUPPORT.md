# サポート / Support

[English](#english)

## 日本語

### 使い方で困ったとき

手順書の「[困ったとき](guide/ja.md#困ったとき)」を見てください。同じ手順書は、配布用の zip の中にも `はじめに.txt` として入っています。

### 不具合の報告

不具合は、GitHub の Issues の「不具合の報告 / Bug report」のフォームから報告できます。

cordmux の設定の [バージョン情報] ページの [診断情報をエクスポート] で作る zip は、自分で原因を調べるときや、詳しい人に相談するときに使います。Issue には添付しないでください。スクリーンショットを添付するときは、ほかの人の名前が写っていないかを確認してください。

### 脆弱性の報告

脆弱性は Issue に書かないでください。報告の方法は [SECURITY.md](SECURITY.md) にあります。

## English

### Help with Using cordmux

See "[Troubleshooting](guide/en.md#troubleshooting)" in the guide. The same guide is also in the distribution zip file as `README-en.txt`.

### Reporting Bugs

You can report bugs in GitHub Issues with the "不具合の報告 / Bug report" form.

The zip file you create with [Export Diagnostics] on the [About] page of cordmux Settings is for looking into the cause yourself or asking someone familiar with it. Don't attach it to an issue. If you attach a screenshot, check that it doesn't show other people's names.

### Reporting Security Vulnerabilities

Don't post vulnerabilities in an issue. [SECURITY.md](SECURITY.md) explains how to report them.
