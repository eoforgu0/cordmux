# src-obs/tests/label_tuner

名前ラベルの調整ツール (`label_tuner.exe`)。合成のソース cordmux の名前ラベルと、話している人を示す光の見た目の値を、つまみを動かしながら決めるための Qt Widgets のウィンドウ。決めた値は、設定のキーの名前の JSON に保存する。

プレビューは、製品と同じコンポーネントだけで描く。

- 名前ラベルと光の画像: 製品の描画 (`sources/composite_label.h` の `paint_composite_label` と `paint_frame_glow`)
- 置く物と順と切り抜き: 製品の計画 (`sources/composite_draw_plan.h` の `plan_composite_draws`)
- 重ねる処理: CPU で計画のとおりに重ねる関数 (`sources/composite_draw_cpu.h` の `draw_composite_plan`。GPU で置く合成のソースと同じ式)
- タイルの位置: 製品の配置 (`sources/composite_layout.h` の `plan_composite_layout`)
- 話している間の明るさ: 製品の関数 (`sources/label_border.h` の `merge_speaking` と、`sources/composite_label_plan.h` の `composite_speaking_level`)
- つまみ: `config::Settings` の値を変え、合成のソースと同じ変換 (`sources/decor_params.h` の `composite_label_look_from_settings` と `decor_label_params_from_settings`) を通す
- 場面を作る部分: 名前ラベルのプレビューツールの見本と同じファイル (`src-obs/tests/decor_preview/composite_scene.h`)。同じ値なら `decor_preview.exe --composite-sample` の PNG とピクセルまで同じになる
- 描き直しのキーと、描き終えるまでに前の画像を置く規則: 合成のソースと同じもの (`sources/composite_label_plan.h`)

合否を持たないので、テスト (`add_test`) には入れていない。

## ビルド

`src-obs/tests` を CMake で構成するときに `CORDMUX_BUILD_PREVIEW_TOOLS` を `ON` にすると、`label_tuner` もビルドする (`decor_preview` と同じ)。実行に要る Qt の DLL と、ウィンドウを開くためのプラットフォームプラグイン (`platforms/qwindows.dll`)、JPEG を読むプラグイン (`imageformats/qjpeg.dll`) は、ビルドの後に実行ファイルのフォルダーへコピーする。

## 起動のしかた

```
label_tuner.exe --save <保存する JSON のパス> [--load <JSON>] [--state <場面>]
```

- `--save` は [保存] で書く先。起動のときにそのファイルがあれば、つまみの値を読み込む。渡さなければ [保存] は押せない。
- `--load` は、起動のときに読み込むつまみの値 (`--save` のファイルより先に使う)。
- `--state` は場面の初めの状態 (下の「--state」)。

ウィンドウを開くのは、この起動のしかたのときだけである。

## 画面

左の列に、配信の画面 (1920 x 1080) 全体を縮めた表示、名前ラベルのあたりの等倍の表示、2 倍の表示を並べる。

- 等倍の表示は、画像の 1 ピクセルを画面の 1 ピクセルで描く (Windows の表示の拡大率を打ち消す)。2 倍の表示は、1 ピクセルを 2 x 2 ピクセルの同じ色にして描く (補間しない)。縁取りと光の細かい所は、縮めた表示では見えないので、この 2 つで見る。
- 等倍と 2 倍で見る範囲は、選んだタイルの名前ラベルとその光に、名前ラベルの側の枠の隅を足した範囲で、枠の境 (光が隣の枠へ出るか) も見える。全体を縮めた表示で枠をクリックしても選べる。
- 見る範囲が表示より大きいときは、名前ラベル (光を含めない) が表示に入るようにスクロールする。入りきらないときは隅の側の端 (左下の名前ラベルなら左端と下端) をそろえる。入ったうえで余裕があれば、名前ラベルの側の枠の境も入れる。スクロールし直すのは、見る範囲、名前ラベルの位置、表示の大きさが変わったときだけで、その間に手で動かしたスクロールは変えない。

真ん中の列は場面である。

- 人数 (1 から 4)。製品の配置のとおり、2 人以上は 4 等分で、人 1 (自分の枠) が左上、ほかの人は名前の順に並ぶ。1 人は全面になる。
- 参加者ごとに、人 (見本の架空の人。長い名前の人とアバターの画像がない人を含む)、[話している]、[プッシュ・トゥ・トーク]、[2 秒話して 1 秒黙る] を選ぶ。名前ラベルを置く隅は参加者ごとには選ばず、つまみの「画面共有している参加者」の「名前ラベルの位置」で全員に一律に決める。明るさは実際の時刻で求め、16 ms ごとに表示を更新する。人の行には、その人の枠の位置と、現在の明るさと、名前ラベルの色の倍率 (暗さ) を出す。人 1 (自分の枠の人) も、ほかの人と同じく話していなければ暗くする (このツールでは自分の枠も光らせられるため。製品の自分の枠の扱いとは別)。
- 画面共有していない参加者の人数 (0 から 8)。製品の並び (`sources/composite_roster.h` の `plan_composite_roster`) で、映像の上に重ねて描き、枠は縮めない。画面共有している参加者の名前ラベルとは互いに干渉しない層として重ね、重なっても避けない (配置は設定の値のとおりに置く)。参加者ごとに、人 (見本の架空の人 12 人から選ぶ。初めの人は、画面共有の 4 人の次の人から順に、アバターのある人とない人、長い日本語の名前、長い英語の名前が混ざる)、[話している]、[プッシュ・トゥ・トーク]、[2 秒話して 1 秒黙る]。[最後の 1 人は声を聞けない] は、名前の順に並べた最後の人を、声の経路を持てない人にする (話しても光らず、暗くもしない)。画面で開いたときは、初めから 3 人を出す (`--state` の `roster` で変えられる)。
- 等倍と 2 倍で見る名前ラベルの選択は、タイル (4 つまで) の後ろに、画面共有していない参加者も並ぶ。全体を縮めた表示には、並びも描く。
- 見本の映像は、見本と同じく枠ごとに違う 4 種類、どの枠も同じ 1 種類 (暗いゲーム画面、明るい空、細かい縞、下側が明るい景色)、開いた画像のファイル (PNG、JPEG、BMP) から選ぶ。画像のファイルは、製品が画面共有の映像を置くのと同じく、縦横比を保って枠に収める。

## 保存の形

[保存] は、上の表のキーだけを、設定のファイル (`settings.json`) と同じキーの名前と値の書き方の JSON で書く。

```json
{
  "label_avatar_ratio": 1.5,
  "label_border_color": "#57F287",
  "label_em_ratio_pct": 2.5,
  ...
}
```

保存先にすでに JSON のオブジェクトがあれば、表のキーだけを置き換え、ほかのキーは残す (保存先を設定のファイルと取り違えても、ほかの設定を消さない)。保存先が JSON のオブジェクトとして読めなければ、書かずに下の行に理由を出す。読み込みは製品と同じ関数 (`config::parse_settings`) で、ないキーは製品の既定値になり、形の違う値が 1 つでもあれば全部を既定値にして、下の行にそのことを出す。このツールの刻みに合わない数は刻みに合わせ、合わせたキーを下の行に出す。

## 重さ

名前ラベルの描き直しは、ぼかしと広がりが大きいと 1 枚 0.5 秒ほどかかる。描き直しはタイルごとの描き直しのスレッドで行い、保存先ごとに最後の仕事だけを描く (`sources/composite_paint_handoff.h`)。描き終えるまでは、合成のソースと同じ規則で前の画像を置き、画面は止めない。

背景に重ねる仕事も画面のスレッドの外で行う。等倍と 2 倍の表示は、見えている所だけを重ねる。全体を縮めた表示は、キャンバス全体を、行を 4 つに分けて同時に重ねる。光が大きい (フォントサイズ 8.5%、ぼかし 3.0、太さ 1.0、対象に枠も入れる) と、全体を縮めた表示は 1 秒に 10 回ほどしか更新できないが、等倍と 2 倍の表示とつまみは止まらない。

## 確認 (ウィンドウを開かない)

`--shot`、`--sweep`、`--drive` は、ウィンドウを開かずに、プレビュー用の Qt のプラットフォームプラグイン `cordmuxdecorpreview` (`src-obs/tests/decor_preview/decor_qpa.h`。OS のウィンドウを作らず、フォントデータベースと文字を混ぜるときのガンマは OBS と同じ) の上でウィンドウを動かす。`--shot` と `--sweep` は描き直しのスレッドを作らず、その場で描き終えてから書き出し、時刻は `--state` で決めた時刻を使う。環境変数 `QT_SCALE_FACTOR` で、表示の拡大率を変えた画像も書ける。

```
label_tuner.exe --shot <PNG> [--canvas <PNG>] [--load <JSON>] [--state <場面>]
label_tuner.exe --sweep <フォルダー>
label_tuner.exe --drive <フォルダー>
```

- `--shot` はウィンドウの画像と、同じ名前の `.json` (つまみの値、画面のつまみが表示している値、つまみのヒント (`hints`)、描いた値、タイルごとの明るさと名前ラベルの範囲、等倍と 2 倍の表示が画像のどこにあるか) を書く。`--canvas` は重ねたキャンバスも書く。`.json` の `view.one` と `view.two` には、名前ラベルが見えている範囲に全部入るか (`label_inside`)、表示より大きいか (`label_fits` が偽)、隅の側の角が入るか (`label_corner_inside`)、名前ラベルの側の枠の隅が入るか (`cell_corner_inside`) を書く。
- `--sweep` は、1 つのプロセスの中で、つまみを 1 つずつ下の端、既定、上の端に、利用者の操作と同じ経路で動かしたウィンドウの画像と `.json` を書く。`.json` の `fresh_mismatch` は、その場で新しく描いた画像と表示の違うピクセルの数で、つまみを変えたのに描き直していなければ 0 にならない。どれかが 0 でなければ終了コードは 1。つまみごとの見本のあとに、画面共有していない参加者の配置 8 か所 x 並び (選べる組だけ) x アバターの位置 (左、右) を、8 人で並べた見本 (`NN_roster_layout_<配置>_<並び>_<アバターの位置>.png`) も書く。既定 (右下、縦並び、アバター右) もこの中にある。画面共有していない参加者に関わるつまみ (表示、配置、並び、間隔、名前の最大幅、アバターの位置、暗さ、背景の表示) の見本は、5 人を出し、参加者 2 が話し続けている (そのほかのつまみの見本は 0 人)。
- `--drive` は、画面と同じく描き直しのスレッド、重ねる仕事のスレッド、16 ms ごとのタイマー、実際の時計で動かし、決めた手順 (`tuner_drive.cpp` の `build_steps`) を、利用者の操作と同じ入口 (スライダー、数の欄、コンボボックス、チェックボックスとボタンへのマウスの押下と離し) から数十 ms の間隔で入れる。最後の操作から 5 秒の内に描き終えるか、そのとき表示がその場で描いた画像とピクセルまで同じか、表示に使った明るさが、記録した押下と離しの時刻から合成のソースと同じ関数で求めた値と同じか (操作の関数の前後の時計の値で幅を取る) を確認し、画面のスレッドの tick の回数と、いちばん長い間を、フォルダーの `drive.png` と `drive.json` に書く。どれかが通らなければ終了コードは 1。

### --state

`名前=値` を `;` でつなぐ。名前の後ろの数字 (1 から 4) は人の番号。

| 名前 | 値 |
|---|---|
| `people` | 人数 (1 から 4) |
| `person1` から `person4` | 人。`mika`、`noa`、`taro` (アバターの画像なし)、`alexander` (長い名前)、`sakura`、`ken` (アバターの画像なし)、`long_ja` (長い日本語の名前) |
| `speak1` から `speak4` | 話している区間 (ms。`--shot` は起動からの時刻。画面で開いたときは、ウィンドウを出した時刻を 0 として実際の時計で切り替える)。`開始-終了` を `,` でつなぐ。終了を書かなければ話したまま。例: `0-1000,1500-` |
| `cycle1` から `cycle4` | 「2 秒話して 1 秒黙る」を始める時刻 (ms。`speak1` から `speak4` と同じ数え方) |
| `bg` | 見本の映像。`mixed` (枠ごとに違う 4 種類)、`game`、`sky`、`stripes`、`snow`、`file:<パス>` |
| `view` | 等倍と 2 倍で見るタイル (0 左上、1 右上、2 左下、3 右下) |
| `roster` | 画面共有していない参加者の人数 (0 から 8。既定は 0。画面で開いたときに `roster` を書かなければ 3) |
| `rperson1` から `rperson8` | 画面共有していない参加者の人 (`person1` と同じ書き方。既定は `sakura`、`ken`、`long_ja`、`rin`、`sota`、`olivia`、`yuzu`、`kumo`) |
| `rspeak1` から `rspeak8` | 画面共有していない参加者の話している区間 (`speak1` と同じ書き方) |
| `rcycle1` から `rcycle8` | 画面共有していない参加者の「2 秒話して 1 秒黙る」を始める時刻 (ms) |
| `runheard` | `1` なら、名前の順に並べた最後の人を、声を聞けない人にする (既定は `0`) |
| `rview` | 等倍と 2 倍で見る、画面共有していない参加者 (1 から 8。名前の順に並べた何番目か) |
| `at` | `--shot` で描く時刻 (ms。既定は 10000) |
| `size` | `--shot` のウィンドウの大きさ `WxH` (既定は `1600x1000`) |
| `focus` | つまみの並びを、このキーのつまみが見えるようにスクロールする |
| `press` | 書き出す前に押すボタン。`save` は [保存]、`reset` は [既定に戻す] |
| `bench` | 書き出した後に、時刻を 16 ms ずつ進めてこのフレーム数を描き、1 フレームの時間を `.json` の `bench` に足す |

既定の場面は、見本 (`decor_preview.exe --composite-sample`) と同じ 4 人、背景は枠ごとに違う 4 種類である。たとえば `--state "speak4=0-;view=1"` は、見本の既定 (右上の枠の人が最大の明るさで話している) と同じ場面になる。ただし暗さの既定 (30 %) が動作するので、話していない人の名前ラベルは暗く描かれる。見本とピクセルまで同じにするには、`label_dim_pct` を 0 にしたつまみの値を `--load` で渡す (`label_show_plate` は既定で `true` で、見本と同じ。画面共有していない参加者は 0 人のときに、見本と同じピクセルになる)。
