# 変更履歴 (Changelog)

## 1.0.1

### ja

#### 変更点

- 参加者が多いときに、声と画面共有の音声の処理で使うCPUを減らしました。

#### 不具合の修正

- 自分の枠を使っている間に、[枠に載せる人の選び方] が「自動」のときや、[自動で枠に載せる] を付けた人が画面共有を始めたときに、4人目が枠に載り、1人が描かれないことがある問題を修正しました。

### en

#### Changes

- Reduced the CPU usage of processing voices and screen share audio when many people are in the call

#### Bug Fixes

- Fixed an issue where a fourth person was added to a slot while the self slot was in use, when [Slot Assignment] was set to "Automatic" or a person with [Add Automatically] started sharing, so one slot wasn't drawn
