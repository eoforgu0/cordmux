# cordmux の説明書

## 概要

cordmux は、通話で画面共有している人の映像と声を OBS に出すプラグインです。

画面共有をする人は、いつもどおり画面共有をするだけです。

## 必要なもの

- Windows の PC
- OBS Studio 33 以上

## インストール

### 1. zip を展開する

1. zip を右クリックして「cordmuxの古い文言」を選びます。

### 2. Vesktop に追加する

1. ドックの [Vesktop に追加] を押します。
2. cordmux の設定の [一般] ページで、[ふだんのアカウントのユーザー ID] 欄に入力します。[名前を表示する] チェックボックスにチェックを付けます。
3. ドックに「Vesktop と接続済み」か「通話中」で始まる行が表示されます。表示されないときは、「困ったとき」を見てください。
4. Discord の [ユーザーIDをコピー] を選びます。

## 配信のたびにすること

1. ドックの [シーンを作成] を押します。OBS に「cordmux 画面共有 1 (空き)」ができます。[自動で載せる] を選びます。

## 更新

1. OBS を閉じます。

## 困ったとき

### ドックが出ない

[cordmux をアンインストール] を選んでから、もう一度インストールします。

## 互換性

仮の行です。
