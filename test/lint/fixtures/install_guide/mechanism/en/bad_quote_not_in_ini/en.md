# cordmux Guide

## Overview

cordmux brings the video and voice of people sharing their screen into OBS.

There is nothing for them to install or set up.

## Requirements

- A Windows PC
- OBS Studio 33 or later

## Installation

### 1. Extract the zip file

1. Open the zip file and choose "Extract all".

### 2. Add cordmux to Vesktop

1. In the dock, press [Add to Vesktop].
2. On the [General] page of cordmux Settings, enter your ID in the [Usual Account User ID] box. Select the [Show Name] check box.
3. A line that starts with "Connected to Vesktop" or "In a call" appears. If it doesn't, see "Troubleshooting".
4. In Discord, select [Copy User ID].

## Updating

1. Close OBS.

## Troubleshooting

### The dock does not appear

Select [Uninstall cordmux], then install again.
