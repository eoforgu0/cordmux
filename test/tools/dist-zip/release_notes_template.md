### 添付ファイル

- `{{zip_asset}}`: cordmux の zip ファイルです。展開して、中の「{{ja_guide}}」のとおりにインストールします。同じ説明書は、見出しと目次の付いた形で [GitHub]({{ja_guide_url}}) でも読めます。既に cordmux を使っている人は、説明書の「[{{ja_update_heading}}]({{ja_update_url}})」のとおりに更新します。
- `{{pdb_asset}}`: OBS が強制終了したときに、原因を調べるためのファイルです。インストールする必要はありません。
- `{{source_prefix}}` で始まるファイル: 同梱したコンポーネントのソースコードです (コンポーネントごとに 1 つ)。

同梱したコンポーネントのライセンスと、ソースコードの入手先は、zip ファイルの中の「{{source_offer}}」にあります。cordmux 本体のソースコードは、「Assets」の [Source code (zip)] と [Source code (tar.gz)] です。

### Attached Files

- `{{zip_asset}}`: The cordmux zip file. Extract it and install cordmux as described in "{{en_guide}}" inside it. You can also read the same guide, with headings and a table of contents, on [GitHub]({{en_guide_url}}). If you already use cordmux, update it as described in "[{{en_update_heading}}]({{en_update_url}})" in the guide.
- `{{pdb_asset}}`: A file for finding the cause when OBS crashes. You don't need to install it.
- Files starting with `{{source_prefix}}`: The source code of the bundled components (one file per component).

The licenses of the bundled components and where to get their source code are in "{{source_offer}}" in the zip file. The source code of cordmux itself is in [Source code (zip)] and [Source code (tar.gz)] under "Assets".
